# Agent Instructions

This file contains instructions for AI agents working on this repository.

## Future Tasks

Here is a list of potential future tasks and enhancements for this project:

- **Pictogram Chips**: Instead of just listing GHS Hazard Codes (e.g., "H319"), display them as visual "chips" or icons for better readability.
- **Typo-Tolerant Search**: Implement a more forgiving search algorithm (e.g., using libraries like Fuse.js) to handle minor typos in user queries.
- **Issue Template for Broken Links**: Create a GitHub issue template specifically for reporting broken SDS/Spec file links. This could be pre-populated with information to help us quickly identify and fix the link.
- **QR Codes**: Add a feature to generate a QR code for each product that links directly to its details view. This could be useful for printing labels for physical containers.
- **Analytics**: Integrate a privacy-respecting analytics service to gather usage data, such as popular search terms or frequently viewed products. This will help guide future development.
